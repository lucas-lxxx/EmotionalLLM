## 一、Observation 初稿

Section 2 整体框架

核心叙事线——表征解耦与因果不对称，三个分析工具递进构建证据链：

### 2.1 音频内部：语义 vs 韵律

**三阶段分层结构**

- 早层 0-14：韵律表征占优（Probe dominance $D \approx +0.15$）
- 中层 14-23：两路融合，14-15 层信号翻转
- 晚层 23-35：语义接管决策

**核心发现：表征优势 ≠ 决策采纳**

- Logit Lens：早层韵律虽然"可读"，但决策分布一直弥散，语义锁定在 L23 后才出现
- Activation Patching（因果证据）：语义 patch Flip-to-Target ~0.63，韵律 patch 仅 ~0.24
- **L14-15 是因果可控性的物理边界**，超过这层局部干预失效

### 2.2 跨模态：文本指令 vs 音频信号

- 文本指令在中层（5-20）建立因果主导，音频韵律被压制
- Claim 边界收缩：限定在"语义中性条件下，文本 > 音频韵律"
- 新增区分：**决策完成 ≠ 决策可读**（模型可能早就决定了，但 Logit Lens 要到更高层才读出来）

## 二、OpenS2S 批量实验

**数据集**：ESD 中文 / 8949 样本 / 9 说话人 / 4 源情绪 → happy

**评估**：3 个 prompt（EoT 同时优化）

### 攻击成功率


|        | Joint ASR  | P1 直接分类 | P2 分类指令 | P3 标签提取 |
| ------ | ---------- | ------- | ------- | ------- |
| **总体** | **78.44%** | 91.42%  | 94.66%  | 81.38%  |


对比之前 pilot study（单 prompt 训练，跨 prompt 仅 20%-50%），EoT 训练显著提升了跨 prompt 鲁棒性。

**按源情绪**：angry 71.21%（最难） / neutral 81.10% / sad 81.54% / surprise 80.58%

**按说话人**：范围 69%-84%，差异不大

### 语义保持


| 余弦相似度均值 | 语义保持率（阈值 0.8） | WER 均值 | 联合成功率（ASR ∧ 语义） |
| ------- | ------------- | ------ | --------------- |
| 0.50    | 20.96%        | 3.24   | **16.24%**      |


攻击能改变情绪判断，但转录受影响较大，语义保持率偏低。

### 扰动幅度

$L_\infty$ = 0.008（固定） / SNR 均值 16.43 dB

### 注意事项

P3 的 clean accuracy 仅 **2.10%**——这个 prompt 格式本身不适配 OpenS2S，P3 的攻击成功率需要打折看。

# 讨论 4.4

## 1. Demo 实验概况

- Voxtral 白盒对抗样本 → 两个闭源商业 API（Gemini 2.5 Flash、Qwen3-Omni-Flash）
- 48 条样本，单 speaker，目标情绪 happy，3-prompt majority vote

## 2. 核心结果

|                        | Gemini 2.5 Flash         | Qwen3-Omni-Flash          |
| ---------------------- | ------------------------ | ------------------------- |
| **Transfer ASR** | **12.50%**（6/48） | **27.08%**（13/48） |
| 白盒基准（Voxtral）    | 94.1%                    | 94.1%                     |

- 传统SER的分类器做替代模型迁移到ALLM上的成功率远低于ALLM作为替代模型迁移到黑盒ALLM上。说明ALLM共享某些脆弱性。
- 5 条样本在两个 API 上同时成功 → 存在跨架构共享的脆弱子空间

## 3. 后续计划

- 完整 n×n 矩阵：500 条样本，(Voxtral/OpenS2S) × (Gemini/Qwen) 。最后形成一张大表格。+ clean baseline
- 随机噪声baseline：用于证明攻击效果来自优化。
- 按照原情绪->目标情绪的拆分迁移率与白盒对比。
- 防御机制对抗。音频领域考虑音频压缩、降噪、音频重采样等。

## 4. 黑盒整体框架

### Part 1：Transfer Attack

- 完整 n×n 矩阵：(Voxtral/OpenS2S) × (Gemini/Qwen) + clean baseline
- 随机噪声 baseline（证明效果来自优化而非随机扰动）
- 按源情绪拆分迁移率，与白盒对比

### Part 2：Defense

- 输入预处理：音频压缩、降采样-升采样、量化、随机平滑
- 对抗检测：频谱统计差异、特征挤压
- 鲁棒推理：多模型投票、prompt 多样化

### Part 3：Physical & Query-based（ ？）

- Query-based：利用 API logprobs 做 score-based 梯度估计，小规模验证
- 物理层 Over-the-Air：扬声器→空气→麦克风→API，距离/环境变量控制

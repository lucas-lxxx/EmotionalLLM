## Part 1: Background（~1.5min）

## Slide 2 — ALLM 与音频情绪

- 音频 ≠ 纯文字转写；同时携带**语义**（说了什么）和**副语言**（韵律、情绪、身份）
- ALLM 代表模型：**OpenS2S** / **Kimi-Audio** / **Voxtral**
- 安全研究现状（各一篇代表作）：
  - 文本 LLM → GCG [Zou et al., 2023]
  - 视觉 MLLM → Mirage [Wang et al., 2024]
  - 音频 ALLM → SpeechGuard [Peri et al., 2024]
  - **情绪维度** → 空白 ← 本研究

## Part 2: Motivation（~1.5min）

## Slide 3 — 已有攻击都在做什么？

- C&W [Carlini & Wagner, 2018] — 攻击 ASR 转写内容
- SpeechGuard [Peri et al., 2024] — 越狱语音指令跟随模型
- WhisperInject [Kim et al., 2025] — 音频扰动越狱 ALLM
- AJailBench [Song et al., 2025] — ALLM 越狱基准
- Feng et al. [2025] — 观察情绪对 ALLM 安全性的影响（非攻击）
- **共同特点**：攻击 ASR 语义 或 安全对齐，无人攻击**情绪感知**

## Slide 4 — 为什么攻击情绪？

**1. 下游决策直接依赖情绪**

- 心理咨询、语音客服、情感陪伴 → 情绪误判导致不当回复策略

**2. LLM 发展趋势：越来越关注人类情绪**

- 具身智能、情感计算与 LLM 融合 [Zhang et al., 2024; Wang et al., 2024]
- LLM 拟人化方向（语音助手、陪伴机器人）→ 情绪感知成为核心能力
- 攻击面随能力扩展而扩大

**3. 隐蔽性极强**

- 扰动不可感知，语义不变，仅改变情绪感知 → 最难检测的攻击形式

## Part 3: Observation（~3.5min，核心）

## Slide 5 — Q1: 音频情绪可以翻转吗？

> Qwen2-Audio-7B-Instruct, audio-only, 400 样本（4 情绪 × 100）✅ 已完成

- Clean 情绪输出**不是 one-hot**，而是 structured preference distribution
- 各情绪稳定性差异极大：

| 情绪    | 候选集准确率    | target gap < 0 比例 | 主要 competitor |
| ------- | --------------- | ------------------- | --------------- |
| angry   | 61.0%           | 39.0%               | sad (0.237)     |
| sad     | 63.0%           | 37.0%               | angry (0.309)   |
| happy   | **15.0%** | **85.0%**     | angry (0.460)   |
| neutral | 24.0%           | 76.0%               | angry (0.355)   |

- **happy 最弱**：85% 样本目标分数低于最强 competitor；**angry 是万能 competitor**
- Prototype 相似性：angry↔happy 最近（JS=0.0195）→ 翻转阻力最小

## Slide 8 — Q4: 情绪表征的内部结构？

> 与 Q1 同批数据，Prototype + Similarity + Confusion 分析 ✅ 已完成

**Prototype posterior**：每类情绪的平均后验分布

- happy 的 prototype **偏向 angry**（angry 概率 0.460 > happy 自身 0.140）
- neutral 不以自身为中心（angry 0.355 > neutral 0.251）
- sad 相对稳定，但仍给 angry 留了不小质量

**Prediction confusion**（行归一化）

| → 预测 | angry           | happy | sad             | neutral |
| ------- | --------------- | ----- | --------------- | ------- |
| angry   | **0.610** | 0.070 | 0.230           | 0.090   |
| happy   | **0.500** | 0.150 | 0.120           | 0.230   |
| sad     | 0.300           | 0.020 | **0.630** | 0.050   |
| neutral | **0.360** | 0.050 | 0.350           | 0.240   |

- happy 最常被判为 angry；neutral 在 angry/sad 间分裂
- → 存在 **anger-oriented overlap region**

**对攻击设计的启示**

- 不宜只用 hard target CE → hybrid margin + soft distribution steering
- 需 pair-specific 策略（尤其 happy→angry、neutral→angry）

## Part 4: Design（~1min）

## Slide 9 — 攻击框架（方法论迭代中，非最终版）

$$
\mathcal{L}(x') = \lambda_{\text{emo}} \mathcal{L}_{\text{emo}} + \lambda_{\text{asr}} \mathcal{L}_{\text{asr}} + \lambda_{\text{per}} \mathcal{L}_{\text{per}}
$$

| 损失项                       | 作用     | 机制                                    |
| ---------------------------- | -------- | --------------------------------------- |
| $\mathcal{L}_{\text{emo}}$ | 情绪翻转 | Teacher-forcing CE on 情绪 token logits |
| $\mathcal{L}_{\text{asr}}$ | 语义保持 | 转写 Prompt 下自一致约束                |
| $\mathcal{L}_{\text{per}}$ | 感知质量 | 多分辨率 STFT 幅度差                    |

- **两阶段调度**：Stage A（20步）情绪优先 → Stage B（40步）兼顾语义+可闻
- **多 Prompt 集成**：3 个情绪 Prompt 损失求平均
- **EoT 增强**：随机时移 + 增益扰动
- 约束：L∞ ≤ 0.008

> ⚠️ 当前为 v1 方法论。Q4 实验提示需引入 soft distribution steering / pair-specific 策略，方法论将据此迭代。

## Part 5: 白盒实验结果（~1.5min）

> **结论先行**：两个模型上情绪翻转均高度有效（78–94%），语义保持率差异大，是核心瓶颈。

## Slide 10 — 攻击成功率

| 模型    | 数据        | 样本量 | ASR（多数投票）  | 单 Prompt 最高 |
| ------- | ----------- | ------ | ---------------- | -------------- |
| OpenS2S | ESD         | 8949   | 78.44%           | 94.66%         |
| Voxtral | ESD (EN+CN) | 2000   | **93.80%** | 99.90%         |

Voxtral 按源情绪：sad 96% / surprise 95% / angry 92% / neutral 92%

## Slide 11 — 语义保持与扰动质量

| 指标       | OpenS2S             | Voxtral              |
| ---------- | ------------------- | -------------------- |
| 语义保留率 | 19.43%（LLM Judge） | 39.75%（Cosine Sim） |
| 联合成功率 | 15.07%              | 36.40%               |
| 平均 SNR   | 16.43 dB            | 20.60 dB             |

- 语义保持是联合成功率的限制因素
- Voxtral 优于 OpenS2S，可能与架构差异有关

# 4.18 会议纲要｜补充实验进展

## 1. 新增白盒目标：MERaLiON-2-3B

新加坡 A*STAR 研发的开源语音-文本多模态模型，显式面向 paralinguistic 任务（情绪、韵律、口音等）训练。

| 项            | 取值                                                                 |
| ------------- | -------------------------------------------------------------------- |
| 全名          | MERaLiON-2-3B (`/data1/lixiang/MERaLiON-2-3B`)                     |
| 总参数        | ~3B                                                                  |
| Audio encoder | Whisper-large v3 风格（128 mel bins，n_fft=400，hop=160，30s chunk） |
| LLM backbone  | 指令微调的 3B 级 decoder                                             |
| 上下文语种    | 英文 + 11 种东南亚语言（含新加坡英语、马来语、泰米尔等）             |
| 训练重点      | 多语种 ASR +**paralinguistic 显式监督**（情绪/语调/说话人）    |
| 推理范式      | 单 prompt 音频问答；本项目用 3 条 prompt 多数表决评估情绪            |

**选它的原因**：

- 与 Voxtral（隐式）、OpenS2S（模块化）构成三种情绪路由设计的完整对照
- 显式 paralinguistic 训练让它的情绪决策边界**局部更锐**，适合检验攻击在"理想目标"上的上界
- 支持 EN + CN，匹配 ESD 双语评估需求

**攻击配置**（与另两个模型对齐）：

- L∞ = 0.008，SGD lr=0.003
- 两阶段优化：stage-A 20 步（λ_emo=1, λ_asr=1e-4），stage-B 40 步（λ_asr=1e-2, λ_per=1e-5）
- 多分辨率 STFT 感知损失（fft=256/512/1024）
- 4 数据集 × 60 样本 = 240 对抗样本（CN 因一条 loader skip 实为 239）

## Experiment

### 1. 两模型核心指标对比

| 指标                       | OpenS2S (N=8949) | Voxtral (N=2000) |
| -------------------------- | ---------------- | ---------------- |
| ASR                        | 78.44%           | 93.80%           |
| 语义保留（DeepSeek Judge） | 19.43%           | 33.30%           |
| 联合成功率                 | 15.07%           | ~31%             |
| SNR / L2                   | 16.4 dB / 1.10   | 20.6 dB / 0.73   |
| Clean Accuracy             | 90.19%           | 27.50%           |
| 收敛步数                   | 39.5             | 5.4              |

### 2. Voxtral 子集差异

| 指标              | EN (1000) | CN (1000) |
| ----------------- | --------- | --------- |
| ASR               | 91.40%    | 96.20%    |
| 语义保留（Judge） | 39.10%    | 27.50%    |
| WER 均值          | 0.53      | 1.29      |

### 3. 注意事项

1. **Voxtral Clean Accuracy 极低（~27%）** — 因为Voxtral模型不是情绪感知模型
2. **CN 语义保留远低于 EN** — WER 翻倍，中文 ASR 质量是主因
3. **Voxtral 收敛极快** — 情绪决策边界脆弱，更小扰动即可翻转
4. **DeepSeek Judge 比 Cosine Sim 更严格** — 建议以 Judge 为主指标

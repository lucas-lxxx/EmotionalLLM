## Major Issues (必须修复)

### M1. Fig 2.4 / 2.5 注释导致 2.2 无图支撑
2.2.2 引用了 `\ref{fig:cross_logit}` 但图被注释掉，编译时会产生 undefined reference。2.2 整节没有任何图表，与 2.1 的四张图形成巨大反差，Reviewer 会质疑跨模态证据的充分性。
**修复**：至少需要取消注释 Fig 2.4（已有数据可画），或移除引用改为纯文字描述。

### M2. 2.2 节过于单薄
2.1 有 ~60 行正文 + 4张图，2.2 只有 ~30 行 + 0张图。结构失衡。
**修复**：(1) 补充实验细节；(2) 添加参数汇总表；(3) Fig 2.4 至少用文字描述替代。

### M3. Probe 实验缺少交叉验证说明
当前只说"训练线性Probe分类器"，未提及 GroupKFold 5-fold CV（按 text_id 分组）。Reviewer 会质疑是否存在数据泄露。
**修复**：在 2.1.1 或 2.1.2 补充一句交叉验证方法。

### M4. Logit Lens 缺少 readout position 说明
未说明投影的 token 位置（最后一个输入 token）。对于非专业读者，这一技术细节影响理解。
**修复**：在首次介绍 Logit Lens 时加一句说明。

## Minor Issues (建议修复)

### m1. "决策deliberation" 中英混杂
应改为"决策权衡"或将 deliberation 斜体化。

### m2. Fig 2.1 caption 说"±1标准差"但应明确来源
这是 5-fold CV 的标准差还是 Bootstrap CI？需要统一。

### m3. Layer 缩写不一致
有时用"Layer 0--14"，有时用"L0--14"。应统一为一种。

### m4. 缺少关键参数汇总表
2.2.4 的"关键架构参数汇总"用文字列举，不如用小表格更直观。Reviewer 更容易快速抓住核心。

### m5. 2.1.1 未提及 TTS 系统名称
"TTS合成"但未指明用什么系统，Reviewer 会要求补充可复现性信息。

### m6. Activation Patching 未说明 audio span 的定义
"audio span区域"在首次出现时应给出明确定义（音频 token 展开后的隐状态区间）。

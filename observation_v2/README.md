## 一、重构动机

当前 Observation (v1) 与白盒方法论之间存在根本性的逻辑断裂：

| 问题 | 具体表现 |
|------|---------|
| **组织轴错位** | v1 按分析工具组织（Probe → Logit Lens → Patching），叙事主线是"ALLM 如何处理情绪"，读起来像独立的机理研究 |
| **观察与方法脱钩** | 五条发现与三个损失函数（$\mathcal{L}_{emo}$ / $\mathcal{L}_{asr}$ / $\mathcal{L}_{per}$）之间没有可追溯的设计推导；去掉 Observation，攻击方法不需要任何修改 |
| **缺少安全问题驱动** | v1 回答的是"模型内部发生了什么"，而安全论文需要回答的是"这对攻击/防御意味着什么" |

**v2 目标**：将 Observation 从"机理展示"重构为"漏洞解剖"——以安全问题驱动叙事，每个观察推导出一条攻击设计要求。Observation 负责定义"必须做什么"，Methodology 负责回答"具体怎么做"，二者之间不越界。

## 二、新叙事框架

### 2.0 核心转变

- **v1 组织轴**：按工具（Probe → Logit Lens → Patching → 跨模态）
- **v2 组织轴**：按安全问题（能不能攻击 → 为什么能 → 约束是什么）

### 2.1 三问结构

三个递进的安全问题构成叙事骨架：

| # | 安全问题 | 小节 | 核心结论 | → 设计要求 |
|---|---------|------|---------|-----------|
| 1 | **是否存在可利用的内部攻击面？** | 2.1 | 音频表征中存在可定位的因果控制面（L0-12），情绪输出可被定向操纵 | → R1: 攻击面存在，攻击应针对模型原生决策路径 |

## 三、各节详细设计

### Section 2 总领段

**功能**：交代分析对象、工具、方法论声明，预告三个子节。

**要点**：
- 在设计攻击前，需先解剖 ALLM 情绪处理机制，识别可利用的结构性脆弱点
- 分析对象：OpenS2S（35 层），247 条语义-韵律冲突/一致样本（TTS 合成） + 18 条跨模态样本
- 三种分析工具按证据强度递进：Probe（表征可读性）→ Logit Lens（决策轨迹）→ Activation Patching（因果干预）
- 方法论声明：**表征可读性 ≠ 决策采纳 ≠ 因果控制**，三者性质不同，需分别解读
- 预告结构：我们依次回答三个问题——能不能攻击（2.1）、为什么能（2.2）、约束是什么（2.3）

---

### 2.1 攻击面识别：音频表征中的定向因果控制

**核心问题**：ALLM 内部是否存在可定位的因果控制面，使得情绪输出可被定向操纵？

**注意边界**：本节证明的是"模型内部存在可利用的攻击面"，而非"输入波形层面的攻击已经可行"。后者还需要输入扰动能通过 audio encoder 映射到达内部控制面——这是 Methodology 的任务。

**论证策略**：以 Activation Patching（最强因果工具）为主体证据，Logit Lens 为辅助。直接回答核心安全问题，而非从弱证据缓慢构建。

**论证链**：

**(1) 语义通道具有强定向因果控制力**

- 实验设计：100 语义对 + 100 韵律对，逐层替换 audio span 表征
- 语义 Patch：Flip-to-Target ≈ 0.63（L0-12），Delta Logit ≈ 5-6
  - 输出系统性偏向源样本情绪标签 → 定向控制，非随机扰动
- 韵律 Patch：Flip-to-Target 仅 ≈ 0.24，方向不稳定
  - 韵律替换只产生弱、非定向的扰动效果
- **核心事实**：语义 = 定向因果控制，韵律 = 弱扰动

**(2) 攻击面是可定位的，而非弥散的**

- 因果控制窗口：L0-12（audio span 内有效区间）
- 扩散边界：L14-15，之后信息扩散至全局表征，局部干预失效
- 决策结晶窗口：L22-28（Logit Lens 辅助证据）——语义决策在此区间锁定，扰动信号需在此前注入
- 熵轨迹佐证：L12 处熵骤降（$\Delta H = -0.66$ bits），L21-24 处出现 deliberation rebound

**(3) 安全结论**

- 模型情绪决策具有**可定位的因果基础**：语义表征替换在 L0-12 可实现 63% 的定向翻转——这是内部攻击面的存在性证据
- 但"内部可控" ≠ "输入空间可攻击"：从表征替换到波形扰动之间，还需经过 audio encoder 的非线性映射
- 本节提供的是攻击的**存在性前提**，后续需分析脆弱性来源（2.2）和利用约束（2.3）

**图表**：Patching Flip-to-Target + Delta Logit 对比图（语义 vs 韵律）；可附 Logit Lens 决策轨迹作为辅助

**→ 设计要求（R1）**：
- 攻击面基于模型原生决策路径 → 攻击优化目标应直接作用于模型自身的情绪输出空间，而非依赖外部分类器或代理信号
- 因果控制窗口集中在 L0-12 → 输入扰动需能通过 audio encoder 到达这些层区间（具体如何实现是 Methodology 的问题）

### 2.2 脆弱性根因：语义单通道依赖

**核心问题**：2.1 揭示语义 patch 有效而韵律 patch 无效——结构性原因是什么？

**论证策略**：用 Probe + Logit Lens 解释 2.1 中的因果不对称，揭示单通道依赖的安全含义。

**论证链**：

**(1) 韵律信号被"感知"但未被"采纳"**

- **Probe 证据（表征层）**：韵律在 L0-14 表征可读性显著高于语义（$D \approx +0.15$，L5 处峰值 $D = 0.215$）。模型的音频编码器确实捕获了丰富的韵律特征。
- **Logit Lens 证据（决策层）**：尽管韵律表征占优，决策轨迹中 Margin $\approx 0$（L0-22），语义锁定在 L23+ 出现。韵律的表征优势从未传导至决策输出。
- **核心事实**："感知" ≠ "采纳"——韵律信息存在于表征中，但模型的情绪决策完全忽略它。

**(2) 情绪决策是单通道的**

- 综合 2.1 因果证据 + 本节表征/决策证据：
  - 语义：有表征、有决策影响、有因果控制力 → **唯一决策通道**
  - 韵律：有表征、无决策影响、无因果控制力 → **被忽略的冗余信号**
- 模型没有利用韵律作为交叉验证或冗余校验通道

**(3) 安全含义：单通道依赖 = 单点故障**

- 如果模型同时依赖语义和韵律做交叉验证（例如：语义说"快乐"但韵律听起来"悲伤" → 模型产生怀疑），攻击者需要同时操纵两个通道，攻击复杂度和扰动代价大幅上升
- 但实际上模型完全不做韵律校验 → 攻击者只需操纵语义通道 → **单点故障**
- 这解释了为什么相对简单的波形优化即可达到高定向翻转率

**(4) 泛化推断（推测，需验证）**

- 单通道依赖更可能是多模态融合架构的**固有倾向**而非 OpenS2S 特有：Transformer 通过注意力机制自动学习信号优先级，训练数据中语义是情绪判断的主要依据
- 此推测将在 Section 5 通过跨模型实验（Voxtral / Kimi-Audio）检验

**图表**：Probe 准确率 + $D(\ell)$ 曲线；Logit Lens Margin + Win-rate

**→ 设计要求（R2）**：
- 单通道依赖 → 攻击目标明确为语义通道，无需同时操纵韵律特征
- 但语义通道同时承载内容信息 → 引出 2.3 的内容保持瓶颈

### 2.3 利用约束：通道耦合与条件化决策

**核心问题**：漏洞存在（2.1）且成因明确（2.2），但从"内部可控"到"输入空间可利用"之间有哪些结构性障碍？

**本节定位**：与 2.1/2.2 不同，本节不是同等强度的 empirical finding，而是**基于前述观察推导出的利用约束**。约束一主要基于逻辑推导，约束二基于先导实验。二者的证据等级需在行文中明确区分。

**论证策略**：从 2.1-2.2 的发现中推导出两个攻击设计必须解决的结构性约束。

---

#### 约束一：语义-情绪通道耦合 → 内容保持是结构性瓶颈

**推导链**：

1. 语义是唯一因果通道（2.2 已证）
2. 但语义通道同时编码两类信息：
   - **语言内容**："他今天考试得了第一名"
   - **内容携带的情绪倾向**：正面/积极
3. 二者共享因果控制窗口（L0-12）内的表征子空间
4. 因此：操纵语义表征以翻转情绪 → **必然同时扰动语言内容**
5. 结论：**内容保持不是一个可以通过简单正则化解决的优化技巧，而是一个由通道耦合决定的结构性瓶颈**

**安全含义**：
- 攻击设计必须显式引入内容保持机制，且该机制需要足够强力以对抗情绪翻转优化对内容的副作用
- 这解释了为什么单纯的情绪翻转优化（只有 $\mathcal{L}_{emo}$）虽能达到高 ASR，但语义保留率低
- 预期：联合成功率（情绪翻转 $\wedge$ 语义保留）会显著低于单独的 ASR

**→ 设计要求（R3）**：
- 攻击设计**必须**包含显式的内容保持机制，且该机制需足够强力以对抗情绪翻转对内容的副作用
- 情绪翻转与内容保持之间存在结构性张力，优化策略需在两个目标之间做显式权衡

---

#### 约束二：Prompt 条件化决策边界 → 跨 Prompt 鲁棒性

**跨模态实验证据**：

1. **Logit Lens**（N=18 per condition）：
   - 文本指令对音频情绪的覆盖在 L22-28 **突然涌现**（非全程压制）
   - Audio-only 条件下 $\Delta\text{logit} \to -5$（倾向音频情绪）；Conflict 条件下 $\Delta\text{logit}$ 在 L22-28 急升至 $+10$（文本覆盖）
   - 涌现窗口与 2.1 的决策结晶窗口（L22-28）高度重叠 → 统一仲裁区间

2. **Activation Patching**（先导研究，N=3）：
   - PatchText Flip Rate ≈ 0.55-1.0（L0-15），Logit Shift 在 L5-20 维持正值
   - PatchAudio Flip Rate 仅 0.2-0.4，不稳定
   - 文本通道在中层建立因果主导，音频被结构性冲刷

**推论**：
- 模型的情绪决策边界受 Prompt 条件化：同一音频扰动在不同 Prompt 下可能成功或失败
- 单 Prompt 优化的攻击在部署环境中（Prompt 不可控）可能失效
- **攻击鲁棒性 ≠ 单 Prompt 成功率**

**→ 设计要求（R4）**：
- 攻击**不能**仅对单一 Prompt 优化，必须考虑 Prompt 变化下的鲁棒性
- 部署环境中 Prompt 不可控，攻击有效性需跨 Prompt 泛化

**限制声明**：跨模态 Patching 为先导研究（N=3），因果结论置信度有限，"结构性冲刷"为待验证假说。

---

#### 跨模型预测（克制表述，验证交由 Section 5）

上述脆弱性与约束源于多模态融合架构的共性（注意力驱动的信号优先级学习、语义在训练数据中的主导地位），而非 OpenS2S 的特殊设计。由此可提出两个**可检验但未验证的预测**：

1. **非情绪专用 ALLM 可能同样脆弱**：没有 deliberate 情绪处理路径的通用模型，决策边界可能更模糊、更易翻转（Section 5 通过 Voxtral / Kimi-Audio 白盒实验检验）
2. **黑盒迁移可能部分可行**：如果音频编码器共享预训练范式，对抗扰动可能跨模型保持部分效力（待 Section 5 验证，目前为假说）

**注**：Observation 不对这两个预测提供证据，仅提供架构层面的推理动机。

### Section 2 收束段

**功能**：汇总三条设计原则，过渡到 Threat Model / Methodology。

**内容**：

上述观察揭示了 ALLM 情绪处理的结构性特征，并推导出四条设计要求：

| 观察 | 结构性特征 | 设计要求 |
|------|-----------|---------|
| 2.1 | 可定位的因果控制面 | R1: 攻击应针对模型原生决策路径 |

## 四、Observation → 设计要求 → 方法论响应（三层映射）

**层级原则**：Observation 输出"设计要求"，Methodology 输出"具体实现"。Observation 不需要解释方法论的每一个工程细节（如 $\mathcal{L}_{per}$、EoT 数据增强等），只需要解释方法的核心形状。

| Observation 发现 | 设计要求（Section 2 输出） | 方法论响应（Section 4 职责） |
|---|---|---|
| 2.1: 存在可定位的内部因果控制面 | R1: 攻击应针对模型原生决策路径 | Methodology 决定具体优化目标形式 |
| 2.2: 语义单通道依赖，无韵律冗余 | R2: 攻击目标为语义通道 | Methodology 决定如何通过波形扰动间接操纵语义表征 |
| 2.3a: 语义-情绪通道耦合 | R3: 必须显式处理内容保持 | Methodology 设计内容保持机制及优化调度 |

**不属于 Observation 职责的方法组件**（由 Methodology 独立论证）：
- 感知约束（$\mathcal{L}_{per}$）：来自对抗攻击的通用不可感知性要求，不需要 Observation 铺垫
- EoT 数据增强：来自部署鲁棒性的工程考量
- 扰动预算（$L_\infty$）：来自 Threat Model 的攻击者能力定义

## 六、待讨论问题

### Q1：证据呈现顺序

v2 从 Activation Patching（最强因果工具）开始，打破了 v1 的递进证据链（Probe → Logit Lens → Patching）。在安全论文中这更合适（直接回答核心安全问题），但 Patching 实验设置较复杂，可能需要更多铺垫。

**备选方案**：在 2.1 开头用 1-2 段简要交代实验设置和 audio span 概念后直接展示 Patching 结果；或在总领段中统一交代三种工具。

### Q2：泛化推断的论证强度

从单一模型（OpenS2S）推断到"所有 ALLM 的架构性质"，论证链的每一步是否可接受？是否需要在 Observation 中包含至少一个跨模型证据点（如 Voxtral 的 Probe），还是完全推迟到 Section 5？

### Q3："语义-情绪通道耦合"的直接证据

约束一目前主要基于逻辑推导（语义控制情绪 + 语义承载内容 → 耦合），但缺少直接实验证据证明"L0-12 的因果窗口同时编码了内容信息"。是否需要补充 L0-12 内容 Probe 实验？

### Q4：Section 2 标题

v1 标题："Emotion Representation Hierarchy and Cross-Modal Dominance"（偏机理描述）

建议备选：
- A: "Vulnerability Anatomy of ALLM Emotion Processing"
- B: "Dissecting the Attack Surface in Audio-Language Models"
- C: 保持中性描述风格，安全含义在正文中体现

### Q5：2.3 泛化部分的位置

当前设计中，泛化讨论放在 2.3 末尾。是否应独立为 2.4？独立的好处是层次更清晰，风险是篇幅膨胀。

### Q6：非情绪 ALLM 的讨论深度

"不基于情绪的 ALLM 是否可攻击"这一问题的回答更多依赖实验数据（Voxtral 结果）而非机理分析。在 Observation 中只能给出架构性推测。这种"Observation 中推测 → Section 5 中验证"的安排是否合理，还是应调整论文结构让 Observation 包含更多实验证据？

### Q7：跨模态 Patching 数据缺口

N=3 是否足以支撑约束二的论证？如果扩展实验短期不可行，如何在论文中处理这一限制？选项包括：(a) 明确标注先导研究限制；(b) 弱化因果 claim，改用 Logit Lens 作为主体证据；(c) 将约束二定位为"observational hypothesis"而非"established finding"。

# Observation 重构方案汇报

---

## 2.1 攻击面识别（能不能攻击）

- **证据**：Activation Patching（因果干预），100 语义对 + 100 韵律对
- **关键数据**：语义 Patch Flip-to-Target ≈ 0.63 / 韵律 Patch 仅 ≈ 0.24 且方向不稳定
- **架构参数**：因果控制窗口 L0-12，扩散边界 L14-15，决策窗口 L22-28
- **Claim 边界**：证明的是"内部攻击面存在"，不等于"输入波形攻击已可行"
- → **R1**：攻击优化目标应直接作用于模型自身的情绪输出空间

## 2.2 脆弱性根因（为什么攻击）

- **证据**：Probe（表征可读性）+ Logit Lens（决策轨迹）
- **核心发现**：韵律在早层表征占优（D ≈ +0.15），但决策轨迹中 Margin ≈ 0 → 表征优势从未传导至决策
- **安全含义**：模型不做韵律交叉验证 → 攻击者只需操纵语义通道 → 单点故障
- **泛化**（推测）：单通道依赖可能是多模态融合架构的固有倾向，非特定模型问题
- → **R2**：攻击目标明确为语义通道

## 2.3 利用约束

**定位**：不是与 2.1/2.2 同等强度的实验发现，而是基于前述观察推导出的设计约束。

**约束一：语义-情绪通道耦合**（逻辑推导）

- 语义是唯一因果通道，但同时承载语言内容和情绪倾向
- 操纵情绪 → 必然扰动内容 → 内容保持是**结构性瓶颈**
- → **R3**：攻击必须包含显式内容保持机制

**约束二：Prompt 条件化决策**（先导实验，N=18/3）

- 文本指令对音频情绪的覆盖在 L22-28 突然涌现
- 同一扰动在不同 Prompt 下可能成功或失败
- → **R4**：攻击必须考虑跨 Prompt 鲁棒性
